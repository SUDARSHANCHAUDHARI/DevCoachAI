# Roadmap

## Phase 1: CLI MVP

- Claude parser.
- Common session model.
- Markdown report.
- Repeated prompt detector.
- Basic anti-pattern rules.

## Phase 2: Codex Support

- Codex parser.
- Project/workspace detection.
- JSON report export.
- Context health scoring.

## Phase 3: Skill Finder

- Repeated workflow grouping.
- Suggested Codex skill names.
- Skill template export.
- Automation value scoring.

## Phase 4: VS Code Dashboard

- Local dashboard.
- Trends and filters.
- Finding drill-down.
- Report export.

## Phase 5: Team Mode

- Optional sanitized aggregate reports.
- Strict privacy controls.
- No raw transcript upload by default.
