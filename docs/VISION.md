# DevCoachAI Vision

Analyze how developers use AI coding assistants.

## Goals

- Improve prompting quality.
- Identify reusable skills and workflows.
- Reduce wasted AI interactions.
- Improve engineering workflows.
- Help developers understand their own AI collaboration habits.

## Target Users

- Individual developers.
- Engineering teams.
- AI-first startups.
- Developers using Claude Code, Codex, Copilot, OpenCode, or similar tools.

## Non-Goals

- Code generation.
- Sending data to cloud.
- Monitoring employees.
- Scoring individual engineers for management.
- Replacing AI coding assistants.

## Product Principle

DevCoachAI should feel like a private training mirror for the developer, not a surveillance dashboard.
